# 校招罗盘功能修复与白灰界面修订说明

日期：2026-10-25。

本轮按优先级修复画像与推荐功能，再将原深色界面改为白灰色调。仍是本地离线演示，双击 frontend/index.html 即可运行，无需后端或网络。

## 功能修复

1. 画像预设切换、恢复预设真正更新草稿；保存前不覆盖已保存画像。
2. 点击右侧预览只查看详情，使用当前草稿评分，不再静默保存。
3. 应届开关即时刷新 Top 5，预览与保存后的规则推荐一致。
4. 实验详情保留选中画像及规则、TF-IDF、混合策略的评分上下文。
5. 开关计数随实际状态即时更新；技能缺口改为岗位要求中尚未具备的技能。
6. “下次自动登录”真正控制登录持久化；取消后仅在当前标签页保留会话，画像与投递仍保存。
7. 增加退出登录，保留投递、画像和账号显示名称。
8. 详情及弹窗约束键盘焦点、屏蔽背景交互，并在关闭或切换弹窗后恢复焦点。
9. 增加“只看收藏”；详情内收藏和投递操作同步更新推荐列表。
10. 离开未保存画像时提供放弃或取消选择，刷新、关闭也会触发浏览器提醒。

## 界面变化

- 浅灰页面、白色卡片、深灰文字、蓝色主操作；同步调整登录、导航、表单、弹层、后台与图表。
- 增大正文和辅助字号，减少光晕与低对比文字；公司信息分行，明确历史岗位样本。
- 手机筛选默认折叠；390×844 下首条岗位从原约 1217 像素提前到约 450 像素。
- 手机底栏补充文字及可访问名称，投递状态切换查看对应列表，指标采用两列布局。
- 画像保存和详情主操作固定可见；完整度圆环使用正确名称。
- 图表在手机上保留可读尺寸并局部横向查看，词云及四分位标线适配浅色背景。
- Offer 不再提供“推进到已结束”的主按钮，结束流程由明确的状态操作完成。

- 375、390、768、1024、1440 像素 × 六个页面，共 30 项布局检查通过；无整页横向撑宽。
- 实际浏览器中未捕获 JavaScript 运行异常；检查并保留桌面、手机截图。
- CSV 已验证生成内容、中文表头及记录数量；受控浏览器实际下载落盘仍未完成确认。

## 使用与验证

正常体验：直接打开 frontend/index.html。旧浏览器中的画像和投递数据可继续使用；“重置演示数据”会清空这些本机记录。

开发者回归命令：

~~~powershell
node scripts/check_frontend.mjs
~~~

检查脚本需要本机 Node.js 与 Chrome；Windows 默认 Chrome 路径为 C:/Program Files/Google/Chrome/Application/chrome.exe，可通过 CHROME_PATH 环境变量指定。它使用独立临时浏览器配置，不操作日常浏览器数据。

源码打包仍使用原有命令：

~~~powershell
python scripts/build_frontend.py
~~~

真实采集、鉴权、后端与真实招聘投递仍为项目已经声明的演示边界。
