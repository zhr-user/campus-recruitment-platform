# 真实账号与白灰动态背景修订说明

日期：2026年10月25日。此次在现有浅色界面和已修复交互的基础上，增加真实账号后端与账号隔离，并完成白灰雾化背景。

## 账号与功能

- 删除预填账号、固定昵称、演示身份选择、账号角色切换、演示重置和自动生成的投递记录。
- 注册、登录、退出和昵称更新均请求真实后端。新账号从空画像、空收藏和空投递记录开始。
- 个人画像、收藏、投递、备注、时间线与偏好保存到账号数据，退出后可恢复。
- 顶部显示同步状态；画像和备注在服务端确认后显示保存成功。网络失败暂停旧队列，显式重试保存当前状态；版本冲突要求刷新。
- 服务器从 Cookie 会话读取身份，校验账号上下文，阻止旧窗口把原账号数据写进刚切换的账号。退出时清空内存、详情内容和旧提示；迟到响应不能改动新账号页面。
- 管理员权限只能由终端授予。普通注册不能创建管理员，前端隐藏后台入口，接口再次鉴权。
- 去掉模拟采集触发和成功日志，未接入的采集服务显示真实空状态；词典提供查询与导出。

## 后端对照

参考用户提供 PDF 第6～7页的3.3节，建立 app/main.py、config.py、database.py、deps.py，以及 models、schemas、routers、services、utils 分层；提供 scripts、tests、requirements.txt 和 .env.example。

已运行技术栈是 FastAPI、Pydantic、SQLAlchemy。默认 SQLite 便于直接使用，可通过 CAMPUS_DATABASE_URL 改用 MySQL 8.0/PyMySQL。真实密码为随机盐 scrypt 哈希，会话令牌只在 HttpOnly Cookie 中传递，数据库保存令牌摘要。已实现会话撤销、到期、同源校验、登录限速、字段白名单和账号版本校验。

当前将每个账号的求职状态作为带版本号的 JSON 记录保存，不是项目书全部表结构的完整实现；会话采用可撤销 Cookie，并非 JWT。岗位与技能来自已有的导入数据，推荐计算沿用前端的实际算法。未构建未接入的爬虫占位服务。

## 视觉与交互

- 白灰径向雾化背景、半透明白色侧栏与登录面板；保留蓝色主按钮与原有页面布局。
- 波纹随鼠标移动生成，方向和延展随移动方向变化，逐渐扩大并淡出。
- 波纹数量和绘制尺寸有限制，停止移动后停止绘制；触屏、后台标签页和减少动态效果设置下停止动态效果。
- 登录注册共用标签切换，支持密码可见性、自动填充、中文错误、提交中禁用和表单校验。
- 手机端保留带文字底栏、折叠筛选、按状态看板和固定主要操作。

## 使用

在项目根目录双击启动平台.cmd，访问 http://127.0.0.1:8791/，点击注册创建自己的账号。直接打开 frontend/index.html 会提示使用本地服务。管理员分配和 MySQL 配置方式详见项目 README。

安全实现参考：[FastAPI 分层路由](https://fastapi.tiangolo.com/tutorial/bigger-applications/)、[SQLAlchemy MySQL 驱动](https://docs.sqlalchemy.org/en/20/dialects/mysql.html)、[OWASP 密码存储建议](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。
